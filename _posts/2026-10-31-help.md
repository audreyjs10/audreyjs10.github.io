In this code, when the button is pressed, the vibe board plays the SOS command using Morse code; when it is unpressed, it plays AUD.


My tip for this project is to give each individual Morese code set (SOS vs. AUD) it's own LED while testing the switch.
This makes it easier to identify wether your switch is working without needing to decipher the buzzing.
At the end, you can change both variables to the one that connects to the vibe board.
