This code means that when the button is pressed, the vibe board plays the SOS command using Morse code; when it is unpressed, it plays AUD.


One tip for this process is that in the early stages of testing, assign the two different code sets different LEDs. This makes it so that when you are testing the button it is more clear when one turns off and the other turns on.
